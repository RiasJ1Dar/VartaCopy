Вибір Explorer / VartaCopy у Провіднику
======================================

Модуль vartacopy_transfer.dll додає вибір перед Ctrl+V та перетягуванням.
Explorer виконує звичайну дію Windows; VartaCopy додає передачу до своєї
черги з перевіркою й журналом. «Скасувати», Escape та закриття вікна
не запускають передачу. Для цього вибору VartaCopy наявне ім'я є помилкою;
посилання блокуються.

Встановлення
------------

В установнику залиште позначеним пункт вибору Explorer / VartaCopy.
Встановлення потребує підтвердження адміністратора Windows.
DLL розміщується в окремому каталозі версії, щоб оновлення не
перезаписувало компонент, який уже завантажений Провідником.

Для portable розпакуйте весь ZIP у постійний локальний каталог.
Запустіть vartacopy-gui.exe, відкрийте «Меню» → «Вигляд і правила…».
У розділі «Вибір під час передачі у Провіднику» натисніть «Увімкнути вибір»
і підтвердьте UAC. Стан та можливу помилку програма покаже в налаштуваннях.
Python, MSIX і тестові сертифікати для цього обробника не потрібні.
Звичайне копіювання в GUI не потребує адміністратора.

Якщо Провідник утримує попередню DLL, перезапустіть його або вийдіть
зі свого облікового запису та ввійдіть знову. VartaCopy не перезапускає
Провідник автоматично й не закриває активні передачі примусово.

Для адміністративного розгортання також доступний нативний CLI::

    vartacopy.exe integration status --json
    vartacopy.exe integration check --json
    vartacopy.exe integration install --json
    vartacopy.exe integration remove --json

install та remove запускайте від адміністратора. CLI визначає GUI та DLL
біля себе або за integration-install.json. Окремі шляхи задаються через
--gui та --dll. Програма перевіряє власність записів, а змінені або чужі
записи не замінює. Перерване налаштування відновлюється з окремого журналу;
у налаштуваннях GUI для цього є кнопка «Відновити інтеграцію».

Видалення
---------

Для встановленої програми використайте «Встановлені програми» Windows →
VartaCopy → «Видалити». Власна реєстрація прибирається до видалення файлів.
Якщо стан змінений і безпечне видалення не підтверджене, видалення
зупиняється, а файли залишаються для відновлення встановлення.

Перед перенесенням чи видаленням portable-каталогу натисніть «Вимкнути вибір»
в налаштуваннях і підтвердьте UAC. Потім можна прибрати каталог.
Історія завдань у %LOCALAPPDATA%\VartaCopy\jobs.sqlite3 та скопійовані
файли зберігаються. Завантажена DLL може залишатися зайнятою до перезапуску
Провідника. Діагностичний запис типово вимкнений.

Перевірено Windows 11 x64, локальну NTFS: Ctrl+C/Ctrl+V Copy, скасування
та ліве перетягування Move на тому самому диску. Ширша матриця Windows,
пристроїв, DPI та допоміжних технологій ще потребує перевірки.
Окреме сучасне контекстне меню Windows 11 зі sparse MSIX є іншим компонентом
і не встановлюється цим установником.
